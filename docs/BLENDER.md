# Blender Integration Architecture

## 1. Overview
Blender serves as the primary external 3D DCC (Digital Content Creation) application for previewing, fine-tuning, and skinning armatures generated by Leocherd Iris Energy.

## 2. Headless Python Execution Mode
Iris Energy generates self-contained Blender Python scripts (`blender/create_armature.py`, `blender/apply_animation.py`, `blender/export_asset.py`) that can execute headlessly:

```bash
blender --background --python blender/create_armature.py -- --input outputs/rig_data.json --output outputs/rigged_scene.blend
```

If Blender is not installed on the host workstation:
- Iris Energy's standalone exporter automatically generates **glTF 2.0 (.gltf / .glb)** and **BVH (Biovision Hierarchy)** files directly through native Python serializers.
- These exported assets open seamlessly in Blender, Unreal Engine, Unity, Three.js, and Godot.

## 3. Armature Generation Protocol
1. **Scene Initialization:** Purges default cube/lamp, sets metric units.
2. **Armature Creation:** Instantiates an `Armature` object and enters `EDIT` mode.
3. **Bone Matrix Construction:** Creates edit bones, sets `head` and `tail` 3D coordinates, and establishes `parent` and `use_connect` relationships.
4. **Pose Mode Animation:** Transitions to `POSE` mode, sets rotation mode to `QUATERNION`, and inserts keyframes for root location and bone rotation channels across frames.
