# Contributing to Leocherd Iris Energy

We welcome contributions to Iris Energy! Please review this document before submitting pull requests.

## Workflow
1. Fork and create a topic branch from `main`.
2. Follow strict typing (`pydantic` dataclasses/models, type hints).
3. Do not introduce dependencies without performance and licensing evaluation.
4. Ensure all tests pass: `pytest tests/`.
5. Run ruff: `ruff check .`.
6. Submit a Pull Request with a clear description and benchmark impact.
